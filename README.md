## 📖 Overview

ThyroAI is an AI-powered healthcare application developed to assist in the early detection and prediction of thyroid cancer using Machine Learning. The system analyzes patient clinical data and provides intelligent predictions to support clinical decision-making.

The project integrates multiple machine learning models into a single web application capable of predicting cancer recurrence, classifying disease stage, estimating tumor size, recommending treatments, and analyzing patient survival outcomes.

> **Disclaimer:** This application is intended for educational and research purposes only and should not be used as a substitute for professional medical advice or diagnosis.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/muntashasamoo/ThyroAI_Project.git
```

Move into the project folder

```bash
cd ThyroAI_Project
```

---

## Create Virtual Environment

Windows

```bash
python -m venv venv
venv\Scripts\activate
```

Linux / macOS

```bash
python3 -m venv venv
source venv/bin/activate
```

---

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

# ▶️ Run the Application

```bash
python app.py
```

or

```bash
python api.py
```
